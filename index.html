카페에서 7년 일하면서 손님이 쓰는 화면보다 일하는 사람이 쓰는 도구에 먼저 눈이 갔습니다. 사장님이 쓰던 프로그램은 늘 손님용 앱보다 불편했습니다. 그때부터 제품을 볼 때 사용자 기능과 운영 도구를 같이 보게 됐습니다.

집무실에서는 워크라운지 앱과 오프라인 지점 데이터를 함께 봤고, 플룸에서는 꽃집 사장님이 쓰는 어드민을 포함해 B2B 커머스를 처음부터 만들었습니다. EAP에서는 기업 임직원용 앱을, 지금은 모네플에서 유저 화면과 운영자 CMS를 함께 기획합니다.

모네플은 25개 커뮤니티가 한 제품을 공유합니다. 한 곳의 요청을 그대로 만들면 다른 곳이 깨지기 때문에, 어디까지 공통으로 두고 어디부터 커뮤니티가 직접 정하게 할지를 먼저 나눈 뒤 개발 가능한 범위와 순서로 정리해 넘깁니다. SQL과 GA로 직접 데이터를 보고, 화면 설계와 정책 문서를 같이 씁니다.

+
상황

기존 검색 관련 페이지 집계에서 게시글로 이동한 비율은 16.7%였습니다. 다만 URL 파라미터 기반이라 검색 실행과 결과 노출을 구분할 수 없었고, 검색창을 못 찾는 문제인지 결과에서 고르지 못하는 문제인지 알 수 없었습니다.

내 역할 — 문제 정의, 화면 사양, GA 이벤트 정의, 배포 후 지표 확인.
판단
화면 개선과 함께 측정 기준을 다시 정의했습니다.

그대로 두면 이번 개선의 효과도 설명할 수 없었습니다. search_execute, search_result_view, post_click 세 이벤트를 정의해 전달했습니다. 배포 전후 수치가 같은 기준이 아니게 되는 점은 감수했고, 결과에도 그렇게 표기했습니다.

검색 엔진 개선은 1차 범위에서 제외했습니다.

형태소 분석이나 랭킹 개선은 백엔드 작업이 커서 2주 안에 결과를 볼 수 없었습니다. 결과가 같아도 고르는 시간을 줄이면 클릭이 는다고 보고, 진입성과 결과 탐색을 먼저 개선했습니다.

전문가 기능 · 제품 구조2025.10 – 2026.08
전문가(코치) 기능 범용화 & 매칭 개선
한 커뮤니티에만 있던 기능을, 인증·매칭 요구가 다른 여러 커뮤니티가 쓸 수 있게 다시 만든 작업
+
상황

전문가(코치) 기능이 특정 커뮤니티에 하드코딩돼 있어, 다른 곳에서 쓰겠다는 요청이 올 때마다 개발이 필요했습니다. 연결 기준도 질문 주제 하나뿐이라 학교·기업·직무 같은 배경으로 코치를 특정해 묻고 싶다는 요구는 받아줄 방법이 없었습니다.

내 역할 — 인증·매칭 방식 결정, 프로필·어드민·CMS 화면 설계, 기존 코치 데이터 이관 범위 정리, QA.
판단
인증 방식을 커뮤니티가 자유롭게 정하게 두지 않고 네 가지로 정리했습니다.

자유롭게 열어주면 심사 기준과 관리 화면이 커뮤니티 수만큼 늘어납니다. 자격증 / 경력·재직 / 학교 / 활동 포트폴리오로 유형을 고정하고 검증 방식은 하나로 뒀습니다. 대신 ‘코치’ 명칭은 커뮤니티가 바꾸도록 열어뒀습니다.

매칭 기준을 하나로 통일하지 않았습니다.

활동분야와 인증정보 두 축을 두고 게시판마다 어느 쪽으로 연결할지 고르게 했습니다. 그 선택에 따라 질문 작성 화면과 코치 답변 화면이 함께 바뀝니다.

커뮤니티 참여 · 운영2026.02 – 06
영향력 기반 커뮤니티 등급제
글 수로 올라가던 등급을 남에게 도움이 된 정도로 바꾸고, 개별 등업 처리에서 벗어난 운영 방식을 만든 작업
+
상황

등급 하나에 세 가지 문제가 걸려 있어 우선순위를 높게 잡았습니다.

  • 품질 — 게시글·댓글 수만으로 등업이 되니 도배로도 올라갔고, 등급이 높다는 게 아무 뜻이 없었습니다
  • 참여 — 유저가 다음 등급 조건을 알 수 없어 계속할 이유가 되지 못했습니다
  • 운영 — 등업을 하나씩 손으로 처리했고, 저품질·신고 글을 다룰 CMS 화면은 없었습니다
내 역할 — 점수 산식과 등급 기준 설계, 유저·CMS 화면 설계, 미적용 커뮤니티 예외 정리, QA. 산식과 등급 구조는 대표 컨펌을 받고 개발에 들어갔습니다.
판단
점수의 중심을 ‘쓴 양’에서 ‘받은 반응’으로 옮겼습니다.

추천·스크랩·댓글을 글 수보다 높게 반영하고 같은 사람이 여러 번 눌러도 한 번만 인정하도록 했습니다. 소수가 서로 눌러주는 방식으로 점수가 오르면 바꾼 의미가 없어집니다. 저품질 판정·신고 누적·도배는 감점으로 뒀습니다.

승급 기준을 절대 점수 대신 상위 구간으로 잡았습니다.
